**[AI News Hub](https://github.com/amir-dev-projects/ai-news-hub/blob/main/README.md)**

  AI News Hub is a personal project that brings AI news, research, tools and learning resources together in one place.

  Instead of visiting multiple websites to follow developments in artificial intelligence, users can browse the latest updates through a single dashboard.

  One of the main ideas behind the project is to go beyond simply collecting news. It also looks at what these developments mean for Program Managers and Product Managers, highlighting useful lessons, skills and opportunities to learn.

  I built the platform to make it easier to follow a fast-changing industry and turn information into practical knowledge.

  The platform generates potential management takeaways from collected articles. I can review, edit and approve the suggestions before they are published.


**[tpm-intake-assistant](https://github.com/amir-dev-projects/tpm-intake-assistant/blob/main/README.md)**

  TPM Intake Assistant is a lightweight application designed to help Technical Program Managers review and assess incoming project requests.

  In many organizations, project requests arrive with incomplete information, unclear objectives, missing dependencies or unrealistic expectations. Reviewing these requests manually can take time and make it difficult to determine which initiatives are ready to move forward.

  I built this application to make the intake process more structured and consistent. It guides users through a series of questions, identifies missing information and potential blockers, and provides an assessment to help determine the next steps.

  The goal is to improve the quality of project intake, reduce unnecessary back-and-forth and help teams make better-informed decisions before committing resources.


**[Clock Learning](https://amir-dev-projects.github.io/clock-learning/)**

  Clock Learning is an interactive educational application designed to help children understand how to read an analog clock.

  Children can move between different learning levels, explore the relationship between hours and minutes, and see how the clock changes as they select different times.

  The application uses visual explanations and interactive exercises to make learning about time easier and more engaging.

  I wanted to build something that makes a traditional learning exercise more interactive, gives children room to explore and allows them to learn at their own pace.


**[AI Explorers](https://amir-dev-projects.github.io/ai-explorers/)**

  AI Explorers is an educational platform designed to introduce children to artificial intelligence in a simple and engaging way.

  The idea is to help children understand what AI is, how it works and where they might encounter it in everyday life.

  Instead of relying on technical explanations, the platform uses stories, illustrations, interactive games and simple experiments to introduce AI concepts.

  My goal is to make AI education accessible to younger learners and encourage curiosity about the technology that is becoming part of everyday life.

**[Clipboard](https://github.com/amir-dev-projects/Clipboard/blob/main/README.md)**

  Clipboard is a macOS productivity application designed to make it easier to manage and reuse copied text.

  We regularly copy information such as links, notes, code snippets, addresses and messages, but finding something copied earlier can be difficult.

  I wanted to build a simple application that provides a convenient place to keep useful text, organize information and find it when needed.

  The application follows a clean, familiar interface inspired by note-taking tools, with a focus on simplicity and ease of use.

  I also explored a local-first approach, keeping information on the user's device.
